# arc-minutxo

ARC workstream on the min-UTxO mechanism.

- [CPS-0037](CPS-0037/README.md) -- the Cardano Problem Statement, published on 27 October 2026 through
  [CIPs PR #1268](https://github.com/cardano-foundation/CIPs/pull/1268).
- [UTxO Deposit Netting for ADA-Free SubTxs](CIP-????/README.md) -- the proposal for
  coexisting minimum-ADA and deposit-backed outputs, transaction-level netting and
  historical deposit accounting. It depends on the formula proposal below.
- [UTxO Storage Cost Formula](CIP-????-utxo-cost-formula/README.md) -- the separate proposal
  for calculating the requirement from asset counts and datum/script payloads.
  It can apply to minimum-ADA outputs independently of deposit-backed outputs.
  Both CIPs are working drafts for discussion, not yet submissions.
- [`backlog/`](backlog/README.md) -- delivery milestones, epics, and work items for
  the ARC min-UTxO stream.
- [`biweekly-reports/`](biweekly-reports/) -- bi-weekly progress reports and the
  reporting template.
- [`SOURCES.md`](SOURCES.md) -- evidence base and reconstruction notes supporting
  the planning material and reports.
- `docs/` -- internal background material. Not for submission.
- `NOTES.md` -- open decisions and claims still to be verified.
