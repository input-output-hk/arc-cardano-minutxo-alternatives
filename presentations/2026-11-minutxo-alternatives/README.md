# minUTxO Alternatives

**November 2026 · Engineering presentation · 32 slides**

Nicolas Henin presents his work with Will Gould and Polina Vinogradova on two questions. Can wallets calculate minimum ADA without serializing an entire output? When an application sends tokens, can it account separately for the ADA that backs those tokens’ place in the live UTxO set?
